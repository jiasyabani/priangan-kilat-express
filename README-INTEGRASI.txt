PRIANGAN KILAT EXPRESS — ADMIN UI STARTER

Pemasangan:
1. Ekstrak ZIP.
2. Salin folder resources dan public ke folder utama project Laravel.
3. Gabungkan isi routes/web.php.snippet ke routes/web.php (jangan menimpa route bawaan).
4. Jalankan: php artisan serve
5. Buka http://127.0.0.1:8000/admin/login

PENTING:
Paket ini adalah starter UI, belum backend produksi. Login/logout, database,
CRUD, nomor resi, kalkulasi ongkir, assignment, redelivery, status history,
aktivasi kurir, reset password, dan setoran COD perlu dihubungkan ke Laravel.
Data dashboard masih contoh. Admin hanya melihat tarif; Manager yang mengubahnya.
Komentar fungsi kode disertakan pada file-file utama.
