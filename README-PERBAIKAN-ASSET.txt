PATCH ASSET PRIANGAN KILAT EXPRESS

Paket ini memasukkan logo Kujang Kilat yang kamu kirim dan memisahkan ikon
pada lembar ikon menjadi file PNG per ikon.

Cara memasang:
1. Ekstrak ZIP.
2. Salin folder public dan resources ke root project:
   C:\xampp\htdocs\priangan-kilat-express
3. Pilih Merge saat diminta menggabungkan folder.
4. Untuk file yang sama, pilih Replace untuk layout, login, dan CSS.
5. Refresh browser dengan Ctrl + F5.

Logo: public/assets/logo-kujang-kilat.png
Ikon satuan: public/assets/icons/
Lembar ikon asli: public/assets/icon-reference-grid.png

Catatan: logo sudah dipasang pada layout dan login. Ikon satuan sudah disediakan
dan akan kita pasang pada menu/tombol yang sesuai saat mengerjakan tiap halaman.
